# Random Project — Study Tracker API

A small Java Spring Boot-style study tracker project.

## Structure
- `src/main/java/com/example/studytracker/` — Java source files
- `src/main/resources/application.properties` — configuration
- `pom.xml` — Maven configuration

## Features
- Add a study session
- List study sessions
- Delete a study session

This is a starter project and can be opened in IntelliJ IDEA, Eclipse, or VS Code.
